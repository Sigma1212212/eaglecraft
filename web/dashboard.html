LAN Worlds

Everything other than the SMP is a LAN world someone opens from their own singleplayer — we don't host these.

Host a LAN: open a singleplayer world → pause → Open to LAN → share the join code with friends.
Join a LAN: Multiplayer → Direct Connect / paste the code your friend shared.

Public access (Dev Tunnels)

Run on the host machine. The login step is interactive — only the person hosting can do it.

1. Install: curl -sL https://aka.ms/DevTunnelCliInstall | bash
2. Log in: devtunnel user login
3. Website: devtunnel host -p 8080 --allow-anonymous
4. The SMP: devtunnel host -p 8100 --allow-anonymous

Pick the nearest cluster to cut latency: devtunnel host -p 8100 -a -c use (use, usw, euw, asse…).
